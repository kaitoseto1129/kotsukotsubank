# コツコツバンク(UI変更のお願い用)

子どもがお手伝い(ミッション)をして、保護者が承認すると、お小遣いが貯まってご褒美と交換できる、4〜10歳の親子向けiPhone/iPadアプリです。SwiftUI + SwiftData で作っています。

このブランチ `ui-redesign-v1.3` は、**App Store で公開中の 1.3 とほぼ同じ状態**です。UIのデザイン変更は、このブランチから、新しいブランチを作って行ってください。

## 動かし方
1. Mac に **Xcode 26.6** を入れる(iOS 26.5 SDK でビルドしています)
2. `コツコツバンク.xcodeproj` を開く
3. 上のメニューで、シミュレーター(iPhone 17 Pro など)を選んで、▶ を押す
4. 最初の画面は「ようこそ」です。ログインか、新規登録が必要です(下の「注意」を読んでください)

## UIを変えるときに触るファイル(`コツコツバンク/` フォルダ内)
| ファイル | 内容 |
|---|---|
| `ParentTheme.swift` | **保護者側の色・ボタン・入力欄・カード**など、共通の部品 |
| `ChildHomeView.swift` | **子ども画面**。豚のゲージ(`PiggyBankGaugeView`)、ミッション一覧、色(`Palette`) |
| `GoalAchievedView.swift` | 目標達成のお祝い(箱が開いて、ご褒美が飛び出す) |
| `ParentDashboardView.swift` | 保護者画面(上の青い帯、メニュー) |
| `TaskManagementView.swift` / `GoalRewardSettingView.swift` / `ProgressManagementView.swift` | タスク管理・ご褒美設定・進捗管理 |
| `WelcomeView.swift` / `LoginView.swift` / `SignUpView.swift` | 最初の画面、ログイン、新規登録 |
| `Assets.xcassets` | 画像。`PigLine`(豚の線画)と `PigMask`(色が入る範囲)は、豚のゲージ用です |

## デザインの方針(現在)
- 白背景に、濃い青(保護者側)と、黄色・オレンジ。グラデーションや影は使わない
- 豚のゲージは、貯めた金額÷目標金額の割合で、下から上へピンク色が満ちる。色は輪郭の内側だけ、線は常に最前面
- 子どもが見る画面なので、文字は大きめ、漢字は少なめ

## 注意
- 保存先は Supabase を使っています。`SupabaseConfig.swift` の鍵は「公開用」ですが、**管理画面のパスワードなど、秘密の情報は、このリポジトリに入れないでください**
- `main` ブランチには、別の変更(端末間の同期)が入っています。**mainには直接pushせず、プルリクエストで提案してください**
- UIの変更のあとは、子ども画面・保護者画面・目標達成の演出を、一通り動かして確認してください
- 見た目を変えるだけで、データの保存や計算(金額・目標)のロジックは、変えないでください
